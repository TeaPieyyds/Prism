# Prism 插件市场审核规范（Review Guide）

> 本文档记录 Prism 插件市场的审核标准、审核流程，以及一次真实的批量审核记录（2026-08-25）。
> 供后续任何审核者（尤其是新人）使用。

---

## 第一条铁律：必须看源码，绝不信任任何描述

**无论插件在 `manifest.description`、名称、作者、介绍文档、甚至是历史审核结果里写了什么，都不能作为评价依据。**

唯一可信的依据，是插件**实际的源码**（`main.lua`）。审核者必须逐行通读源码，确认其真实行为。

原因——本次真实审核已经验证了这一点：

- 有插件 `description` 声称"物品交易系统"，源码却是**网易 Mod SDK 的 Python 代码**（`import mod.server.extraServerApi`），还伪装成 `type: lua`。
- 有插件声称是"兑换码"，源码是 **ToolDelta 的 Python 代码直接照搬**，Python 语法与 Lua 混杂，`def`/`match/case`/`from Crypto import` 全混在一起，**根本无法运行**。
- 有插件的 `description` 是占位文案（如"我是全知的"），与代码毫无关系。

**只看 description 就下结论，会误判。** 凡是描述与实际源码不符的，一律以源码为准。

---

## 审核标准（通过 / 拒绝）

### 通过（PASS）的条件 —— 必须**同时**满足：

1. **语法正确、能够运行**：是合法的 Lua，无致命语法错误/逻辑崩溃。
2. **是 Prism 插件**：确实使用 Prism 暴露的全局 API（`game`、`system`、`api`、`plugin`、`util`、`bot`、`building`、`media`、`world`、`player`、`events`、`http`、`web`），而不是别的框架（ToolDelta、网易 Mod SDK 等）的代码。
3. **声明功能真实**：`manifest.description` 描述的功能，源码里确实实现了。**无虚假宣传**。
4. **无后门 / 不危害服务器与设备安全**：
   - 无恶意隐藏代码、偷偷外联下载、读写与声明功能无关的敏感文件、`system.shell` 执行与声明功能无关的危险命令。
   - **特别说明**：如果插件的功能**本身就是**"输入指令并执行"（例如读文件按行执行命令、玩家输入指令传送），即使它**没有做权限限制**，也不判定为危害，仍可通过。只有"执行了与它声明的功能毫不相关的操作"才算危害。
5. **不重复**：`manifest.id` 未被其他插件占用。

### 拒绝（FAIL）的条件 —— 满足任意一条即拒绝：

- 语法错误 / 无法运行。
- 不是 Prism 插件（是别的框架的代码冒充）。
- 虚假宣传（描述功能与源码不符）。
- 有后门 / 危害服务器或设备安全（执行与声明功能无关的危险操作）。
- 插件 id 重复。

---

## 审核流程

1. **提取源码**：从插件 zip（`data/plugin_market/<hash>/<zip>.zip`）解压 `main.lua` 和 `manifest.json`。
2. **看 manifest 概览**：记录 id / name / version / type / author / description / pre_plugins。**但只作为线索，不作为依据。**
3. **逐行通读 main.lua**：核对语法、使用的 API、每个功能的真实实现、有无隐藏逻辑、有无外联/文件/shell 操作及是否与声明功能相关。
4. **逐条对照标准**：语法 → 是否 Prism → 功能是否真实 → 有无后门 → 是否重复。
5. **结论**：PASS（改库 `review_state=1`）或 FAIL（删源码 + 数据库记录）。

## 结论

- 审核**必须基于源码**，描述、名称、作者、历史都不可信。
- 判断"有无后门/危害"要看它执行的操作**是否与声明的功能相关**；功能本身即执行指令、未加权限限制的，不算危害。
- 本次 21 个待审核插件全部完成：**7 个拒绝**（Python 冒充 Lua / Python 转 Lua 失败无法运行 / 运行崩溃）、**14 个通过**。
- 拒绝的 7 个：`11`、`16`、`17`、`18`、`19`、`20`、`21`。
- 通过的 14 个：`2`、`9`、`13`、`14`、`15`、`23`、`24`、`25`、`26`、`28`、`29`、`30`、`31`、`32`。
